# 使用、数据接口与迁移

## 1. 环境

Python >=3.10；必需 numpy、scipy、matplotlib；验证加 pytest、statsmodels。实际环境为 Python 3.12、numpy 2.3.5、scipy 1.17.0；确切版本由 `validation/python_runtime.json` 保存。Python 低版本兼容是声明的依赖范围，尚未做整个版本矩阵测试。

MATLAB 设计语法范围 R2014b–R2020a：char、struct、函数文件、bsxfun、fminsearch、erfcx、fft、convn、betaincinv、dlmread、dlmwrite、save。未使用 arguments、string、readmatrix、tiledlayout、implicit expansion、jsonencode 等新接口；不需要 Statistics / Optimization / Signal Processing / Image Processing Toolbox。旧版 MATLAB 的 betaincinv、erfcx 等基础函数可用性仍须通过自测实机确认。本次实际跑的是 GNU Octave 9.4.0，不是 MATLAB。

## 2. 表格字段和单位

基础 CSV：

```csv
a,y,status,lower,upper
1.2,2.3,exact,,
1.3,,left,,0.5
1.4,,right,4.0,
1.5,,interval,1.9,2.1
1.6,,missing,,
```

- a：缺陷尺寸，量纲统一；对数变换时要求 >0。没有有限尺寸的记录拒绝。
- y：原始响应特征或 0/1；删失时可空。精确值必须有限。
- status：exact/left/right/interval/missing。未提供时 NaN response 推断为 missing，而不是 left。
- lower/upper：原始响应量纲；left 必须给 upper，right 给 lower，interval 两界都给且 lower<upper。
- group：独立试件/操作者/扫描批次等；是否独立由试验设计决定。
- covariates：明确编码的混杂参数矩阵；分类因素由用户固定基准哑变量编码，禁止带重复截距造成秩亏。

MATLAB 以数值状态 0/1/2/3/4 表示以上五种状态；`data/generated/censored_numeric.csv` 已提供。单位换算对 log 模型截距会产生变化，不能只比较截距而不检查单位。

CLI 仅暴露基础 CSV / NPY 模式；复杂协变量、背景参考、时移和扩展模型通过 Python API 或 MATLAB 函数调用。NPY 中不允许 pickle 对象。仪器专用 DICOM、DICONDE、TDMS、FMC、CIVA/COMSOL 工程文件解析器不在本版内置范围；可先导出数值网格及物理坐标到 NPY/CSV/MAT。

## 3. 基础 POD 的 Python 示例

```python
import numpy as np
from openpod import fit_signal, fit_hitmiss

D = np.genfromtxt('data/generated/censored_numeric.csv', delimiter=',', skip_header=1)
status = np.array(['exact','left','right','interval','missing'])[D[:,2].astype(int)]
model = fit_signal(D[:,0], D[:,1], threshold=2,
                   status=status, lower=D[:,3], upper=D[:,4], missing='mar')
print(model.summary())
print(model.size(.90), model.size_upper(.90, .95))
print(model.size_upper(.80, .90))  # EPRI数值准则；不表示试验已获资格
print(model.pod([1,2,3]))

B = np.genfromtxt('data/generated/hitmiss.csv', delimiter=',', skip_header=1)
hit = fit_hitmiss(B[:,0], B[:,1], link_name='cloglog')
print(hit.size_upper(method='lr', lr_df=1))
print(hit.size_upper(method='profile_one_sided'))
```

改变 y_transform 后阈值仍应以原始量纲输入，函数内部进行一次变换。对数模型中不能输入已经取 log 的 y 再设置 y_transform='log'。

协变量 model 的 `pod` 输入 shape=(n,k)；`size` 输入固定 k 个混杂值。当 covariate 随尺寸变化（例如 log(a)^2 的非线性基函数）时，不能把它固定后计算 size；本版 quantile API 面向固定混杂变量的线性尺寸项。

## 4. MATLAB 示例

```matlab
addpath('matlab');
D = dlmread('data/generated/censored_numeric.csv', ',', 1, 0);
opts = struct('threshold',2,'status',D(:,3),'lower',D(:,4), ...
              'upper',D(:,5),'missing','mar', ...
              'x_transform','log','y_transform','identity');
m = op_fit('signal', D(:,1), D(:,2), opts);
disp([m.a50,m.a90,m.a90_95]);
p = op_pod(m,[1;2;3]);
upper = op_size_upper(m,.80,.90,'wald');

B = dlmread('data/generated/hitmiss.csv', ',', 1, 0);
h = op_fit('hitmiss', B(:,1), B(:,2), struct('link','loglog'));
legacy = op_legacy_band(h,exp(linspace(log(min(B(:,1))),log(2*max(B(:,1))),101))');
```

`model.nll` 是函数句柄，因此可保存成 MAT 并在同版本环境中继续诊断；跨版本交换优先使用参数/协方差 CSV。MAT 格式中的匿名闭包跨版本兼容未逐项验证。

## 5. 信号和空间数据

```python
from openpod.signals import TraceConfig, process_traces, process_field, extract_features
raw = np.load('data/generated/bscan_raw.npy')    # [48,512]
ref = np.load('data/generated/reference.npy')
cfg = TraceConfig(axis=-1, sample_rate_hz=100e6, baseline_samples=100,
                  sg_window=9, align=True, max_shift=14, gate=(150,350),
                  cfar_training=24, cfar_guard=14)
baseline_mask = (np.arange(raw.shape[-1])<100) | (np.arange(raw.shape[-1])>=400)
r = process_traces(raw,cfg,reference=ref,baseline_mask=baseline_mask)
features = extract_features(r,(150,350))
field = process_field(np.load('data/generated/volume_raw.npy'))
```

Python gate=(start,stop) 是 **0-based，stop不包含**；MATLAB gate=[first,last] 是 **1-based，两端包含**。本例 `(150,350)`对应 MATLAB `[151,350]`。时移正数=延迟；输出 shifts_samples 是实际补偿时移。

RF pipeline 时间轴默认最后；MATLAB `time_dim` 是维数编号（从1计）。向量作为单A扫。结果返回 raw/processed/baseline/envelope/CFAR阈值/掩码/波包/时移/归一化因子。Python波包 stop不包含；MATLAB波包终点包含。单位归一化因子必须进入最终报告。

背景参考和对齐参考使用同一 reference 参数；需要二者不同参考的项目应在调用前先做背景校正，或按模块顺序拆开调用。`median_trace`适合缺陷仅占扫描少数位置的情况，满覆盖目标或单迹情况下不合适。不能用目标本身为训练噪声窗口。

```matlab
R = dlmread('data/generated/trace_reference.csv',',',1,0);
opts = struct('baseline_samples',100,'sg_window',9,'sample_rate_hz',100e6, ...
              'align',true,'gate',[151,350],'max_shift',14, ...
              'cfar_training',24,'cfar_guard',14);
r = op_preprocess(R(:,1),opts,R(:,2));
op_plot_preprocess(r,'trace.png');
```

空间场独立使用 `op_field`。Python Gaussian/median边界是反射规则；MATLAB场平滑是截断邻域及边界归一化，因此边缘像素不承诺逐点一致。RF默认流程的跨语言一致性已有验证。

## 6. 噪声与模型辅助

```python
from openpod.noise import fit_noise, threshold_tradeoff
noise = np.random.default_rng(4).lognormal(-1,.3,500)
n = fit_noise(noise,'lognormal')
print(n.summary(pfa=.01,reference=1))
curve = threshold_tradeoff(model,n,np.linspace(.4,3.5,30))

from openpod.advanced import calibrate_simulation, mapod_monte_carlo
sim = np.linspace(0,5,40)
measured = .2+1.1*sim+np.random.default_rng(4).normal(0,.2,40)
cal = calibrate_simulation(sim,measured)
nuisance = np.random.default_rng(5).normal(size=(5000,2))
simulator = lambda a,c: .3+1.6*np.log(a)[:,None]+.3*c[None,:,0]+.2*c[None,:,1]
mp = mapod_monte_carlo(simulator,np.geomspace(.4,7,70),nuisance,2,cal)
```

此 simulator 是示例统计响应生成器，**不是物理超声求解器**。实际模拟器应返回 (n_sizes,n_mc) 响应，经过相同特征/阈值判定。CSV云图必须说明坐标及单位，不能只用着色后的截图代替数值幅值。

## 8. 改变参数后的验证

真实数据应先在独立标准件与背景件上冻结处理流程和阈值，再在盲测缺陷上估计 POD。复核流程：试验/组独立性→单位与门→转换选择依据→删失界→MLE识别→残差/组间差异→置信定义→外推和真实样本复核。不要以最小 a90/95 为唯一目标挑选变换、滤波器和阈值。
